# Conditional Standard core Skill

`core-skill.v1.md` is the only M1 Skill candidate. It is inert distribution
input, not an accepted capability. Chora must keep Standard in its no-Skill
form unless one matched real-task comparison satisfies
`core-skill-comparison.schema.v1.json` and the deterministic evaluator returns
`PASS`.

The repository deliberately contains no favorable comparison record. A missing,
invalid, unmatched, retried, over-budget, or regressing comparison yields
`NO_SKILL`. The schema describes evidence; it does not make evidence true.
