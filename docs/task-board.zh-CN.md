# 任务看板

[English](task-board.md) · [路线图](../ROADMAP.md)

任务视图汇总一个 Project 下各 Room 已有的 Task。从项目的 **任务** 或 Room
的 **任务看板** 进入。可以切换看板/列表，按 Room、仓库、阶段筛选，使用
**需要处理** 找到需要决定、评审、恢复或交付的工作。新建任务仍进入原有流程；
从项目创建时使用默认 Room。

## 阅读看板

一张卡片就是一个 Task，包含它的多次 Run、Attempt 和多个仓库。
五个分组由保留的工作证据推导：

| 阶段 | 含义 |
| --- | --- |
| 准备中 | 初始规划、准备，或已有流程支持的重新规划。 |
| 处理中 | 执行、检查、停止、重试或恢复；不一定有 Agent 正在运行。 |
| 待审阅 | 结果需要评审。计划评审仍属于准备中。 |
| 交付中 | 接受的改动仍需提交、推送、创建 PR、合并或写回本地。 |
| 已结束 | 有证据的结束结果。请阅读具体结果：结束不一定代表成功。 |

所有适用仓库到达其支持的交付终点后，接受的改动才算交付完成。合并、写回本地、
混合交付、无改动、关闭、部分交付后关闭剩余工作都有不同标签。已取消的 Run
仍可能属于可重试的 Task。清理独立于交付：清理失败需要关注，但不撤销已证明的合并。

**待核对** 在五个阶段之外显示缺失或矛盾的证据，不猜测工作已经结束。
详情页保留证据和已有恢复操作。默认隐藏归档任务，勾选 **包含已归档** 可查看。
已归档的 Project 和 Room 保持只读，不授权新工作。

## 导航与刷新

卡片链接打开已有 Task/Run 页面；页面重新读取当前状态后才提供操作。
看板不直接运行、接受、合并、归档或清理工作。读取、筛选和刷新不调用模型，也不创建工作树。
筛选和看板/列表选择保存在 URL 中，浏览器返回时保留。键盘控件和窄窗口堆叠布局提供相同操作。

可见视图大约每两秒刷新，同时最多一个看板请求。隐藏时停止轮询；重新聚焦、联网、
返回时刷新。刷新失败会保留上次卡片并标明过期；首次读取失败显示不可用，不显示空项目。

Room 与仓库筛选每次各加载最多 100 个选项，另保留当前已选但不在该页的选项。
点击“加载更多筛选项”可继续查找；选项分页独立于 Task 分页与任务执行进度。

每页 50 张卡片，计数覆盖全部筛选结果。可加载更多；证据变化时重新分页，
不拼接不一致的快照。查看看板不会停止 Agent、已授权的检查或应用预览。
关闭浏览器标签页后 macOS 应用服务继续运行；正常退出应用遵循已有停止和恢复规则。
重新打开不会自动重启预览或被中断的工作。

## V0 范围

V0 整理已有工作，不包含待办草稿、手动优先级/排序、拖动修改状态、分派、
依赖调度或外部工作项同步。后续方向和实际实施/验证状态见[方案](task-board-plan.md)。
正式签名的 macOS 安装与更新资格独立于任务看板验收。
